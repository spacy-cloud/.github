# SPACY.CLOUD

Web services, automation, game servers and local-first open-source tools on self-managed hardware. No ads, no tracking.

## Projects

- **[self-improvement](https://github.com/spacy-cloud/self-improvement)**: local-first self-improvement app for Android (Flutter). All data stays on the device, no internet permission. [Pre-release v0.2.0](https://github.com/spacy-cloud/self-improvement/releases/tag/v0.2.0) · [Project page](https://spacy.cloud/self-improvement)

- **[agent-box](https://github.com/spacy-cloud/agent-box)** (`abox`): local sandboxes for AI coding agents. Isolated containers and VMs with policy, approvals, egress allowlist and audit; CLI, MCP server, desktop app and Claude Code plugin. Runs entirely on your own machines, no cloud. Release candidate, not yet published.

## Services

- [Game servers](https://gaming.spacy.cloud): live status and connection details for private game servers
- [Naturschutz](https://naturschutz.spacy.cloud): information and engagement around nature and species conservation
